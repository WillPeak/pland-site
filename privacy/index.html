What this notice covers

This notice is for the pland.ai website and the household waitlist on it. It is not an in-app privacy notice. The app's own notice is not copied here.

What the waitlist collects

If you join the waitlist, we ask for:

  • your name
  • your email address
  • household size, in broad terms
  • whether the household uses iPhones

There is also a hidden field meant for bots. If that field is filled in, we treat the submission as spam and do not store it.

The pages themselves are static. We don't add our own analytics. The host (GitHub Pages) keeps its usual request logs, which can include an IP address. We don't copy those logs into the waitlist store, and the waitlist service is written not to log your name or email.

Why we have it

So we can write to you about the household beta, and so we know roughly who the note is for. We don't sell the list, and we don't use it to advertise anything else.

Where it is stored

The form sends those fields to the waitlist service for this site. That service appends them to a private file on the machine that runs it. It does not publish them on pland.ai. If you email hello@pland.ai instead, that message stays in the inbox.

How long

We keep a waitlist entry until we've written to you about the beta, you ask us to delete it, or we no longer need it for the beta — whichever comes first. Email the address above and we'll delete what we have.

Children

The waitlist is for an adult in the household. Don't put a child's name or email in the form. This notice does not describe how any app handles children's information.

Asking for a copy, a correction, or deletion

Email hello@pland.ai from the address you used. We'll send a copy, fix a mistake, or delete the entry.

Changes

If this notice changes, the date at the top changes with it.
